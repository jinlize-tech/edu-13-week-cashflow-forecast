# 十三周现金流预测领域指南

## 业务问题

教培机构存在预收、消课确认、集中发薪和季节性营销支出，账面收入正常仍可能短期缺钱。

## 产品解决方案

以周为单位预测收款、退款、工资、房租、营销和其他支出，输出现金余额、缺口周和情景表。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `opening_cash` | 期初现金余额 | 是 | 本币金额 |
| `collections_schedule` | 十三周预期收款 | 是 | 每周金额和口径 |
| `refunds_schedule` | 十三周预期退款 | 是 | 每周金额与假设 |
| `payroll_schedule` | 十三周工资与提成 | 是 | 每周金额 |

| `scenario_name` | 情景名称 | 否 | 基准、保守或压力情景 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

未来收款和退费是假设，不是保证；必须财务复核；不构成融资、税务或投资建议。
