# JLZ-EDU-SK-092 Codex执行任务书

## 1. 基线

- 任务编号：`JLZ-EDU-EXPANSION-30-FULL-DELIVERY`

## 2. 用户、痛点与目标

- 用户：校长、财务负责人、多校区经营者
- 痛点：教培机构存在预收、消课确认、集中发薪和季节性营销支出，账面收入正常仍可能短期缺钱。
- 目标：以周为单位预测收款、退款、工资、房租、营销和其他支出，输出现金余额、缺口周和情景表。

## 3. 输入契约

| 键 | 名称 | 类型 | 必填 |
|---|---|---|---|
| `opening_cash` | 期初现金余额 | number | 是 |
| `collections_schedule` | 十三周预期收款 | array | 是 |
| `refunds_schedule` | 十三周预期退款 | array | 是 |
| `payroll_schedule` | 十三周工资与提成 | array | 是 |
| `rent_schedule` | 十三周房租与固定支出 | array | 是 |
| `marketing_schedule` | 十三周营销支出 | array | 是 |
| `other_payments` | 其他现金支出 | array | 否 |
| `scenario_name` | 情景名称 | string | 否 |

## 4. 工作流

1. 确认期初现金
2. 分类现金流
3. 设定基准假设
4. 滚动13周
5. 运行保守/压力情景
6. 标记缺口
7. 输出行动清单

## 5. 阶段状态

| 阶段 | 动作 | 退出成果 |
|---|---|---|
| S1_SCOPE_CONFIRMATION | 确认目标、校区/岗位/课程范围、期限、交付格式和可用资料。 | 任务确认单与最多3个关键缺口 |
| S2_EVIDENCE_INVENTORY | 盘点银行/现金余额、应收、预收与消课、未来收款计划、退款、工资、房租、营销、税费、借款和资本支出，标记来源、版本、敏感字段与冲突。 | 证据清单、缺口表和冲突表 |
| S3_PROFESSIONAL_DIAGNOSIS | 围绕以周为单位预测收款、退款、工资、房租、营销和其他支出，输出现金余额、缺口周和情景表。进行专业诊断，形成问题树和优先级。 | 问题树、风险和优先级 |
| S4_SOLUTION_DESIGN | 按确认期初现金 → 分类现金流 → 设定基准假设 → 滚动13周 → 运行保守/压力情景 → 标记缺口 → 输出行动清单设计首选方案和受限备选方案。 | 方案、责任人、完成标准 |
| S5_HUMAN_CONFIRMATION | 由业务负责人复核输入事实、关键假设和最终成果适用范围。 | 确认记录、未决项和升级项 |
| S6_FINAL_DELIVERY | 生成完整交付成果，执行结构、证据、安全、品牌和独立安装检查。 | 最终成果、范围限制和复盘指标 |

## 6. 核心成果

- `13周现金表`
- `缺口预警`
- `关键假设`

## 7. 差异化与排重

- 与现有产品：财务经营分析偏历史指标；月度结账清单管关账；本产品是短期滚动现金预测和压力测试。
- 排重检查：有限重叠；共享财务数据，但本产品输出周级现金流和缺口场景，不做事后报表分析。
- 独立理由：输入现金流假设即可独立使用。

## 8. 安全与人工门禁

- 复核角色：业务负责人
- 复核范围：输入事实、关键假设和最终成果适用范围
- 不调用外部收费API。
- 不自动修改外部系统、执行退款、审批合同、处分员工或联系外部人员。
- 高风险产品完成状态必须确认人工复核。
